Return is the result for the call when the post states a side (long or short), otherwise the price move since the post. For a closed position it is the realized return, frozen at the first bar after the author's closing post; the current price only appears as "if still held". Entry is the first hourly bar at or after the post (daily bars for history older than the hourly window); every value comes from a post_price.v1 record and the daily refresh. Unreached horizons are never shown as 0. Not financial advice.

Score (0-100, quanty.rating.v1): built only from a caller's priced calls, the same records always give the same score. Scored calls state a side and have a price; their result is the realized return if closed, else the return since the post. H = share of scored calls in profit; A = average of 50 + 50·tanh(result / 10%) per call (one outsized call cannot carry it); C = share of calls with an entry that state a side. raw = 0.45 H + 0.40 A + 0.15 C, then pulled toward 50 by sample size: score = 50 + n/(n+10)·(raw − 50). Under 10 scored calls is a small sample, under 30 a limited one. Open calls move with the daily refresh. Each caller page lists every input and every call.
